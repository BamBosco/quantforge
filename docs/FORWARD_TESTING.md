# Forward Testing

Forward testing begins only after a reviewed historical-validation report.
It progresses from replay, to paper/demonstration environment, then a separately
approved constrained-capital phase. Live capital is out of scope for Version 0.1.

Every phase has predeclared duration, allowed instruments, risk profile,
success/failure criteria, rollback procedure, and operator owner. Any data,
reconciliation, risk-control, or execution discrepancy pauses promotion.
