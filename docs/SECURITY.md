# Security

Never commit secrets, account identifiers, API tokens, raw statements, or
personal data. Use least-privilege credentials, external secret injection, and
separate credentials for development, paper, and production environments.

Log security-relevant actions without logging secrets. Protect local databases
and backups, rotate credentials after exposure, and review third-party package
provenance. Live trading requires explicit access-control, audit, and incident
response procedures before enablement.
