# Research Papers

Store a concise bibliographic record and review note for every paper. Prioritize
opening-range breakout, intraday momentum, volatility, market microstructure,
and execution-algorithm studies.

Each note must identify the market, sample period, data frequency, methodology,
cost assumptions, statistical tests, limitations, and whether the result can be
reproduced. An abstract or online summary is not sufficient evidence for a
production decision.
